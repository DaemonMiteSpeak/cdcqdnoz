# cdcqdnoz

Landing page for **Eternet Client**, a visual client for Minecraft. Static site, no build step.

- `index.html`: markup and inline SVG artwork
- `styles.css`: theme tokens, layout and motion
- `script.js`: smooth scroll, navigation and the scroll-driven time of day

## Run locally

```sh
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Before publishing

Text in `{{double braces}}` is a placeholder (supported versions, prices, plan contents, refund terms). The purchase buttons stay disabled until a payment service is connected.
