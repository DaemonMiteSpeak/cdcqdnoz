# Hider — Telegram-бот и Mini App (личный кабинет)

Бот на [grammY](https://grammy.dev) + Mini App (экраны повторяют дизайн из канваса Doop «HIDER — Личный кабинет»).
Бэкенд — Node ≥ 22.5 (встроенный `node:sqlite`), Express. Зависимости: `grammy`, `express`.

## Запуск

```bash
npm install
cp .env.example .env      # заполнить BOT_TOKEN и WEBAPP_URL
npm start
```

1. Создай бота у [@BotFather](https://t.me/BotFather) → `BOT_TOKEN`.
2. Mini App должен открываться по **публичному HTTPS**: выставь `WEBAPP_URL` (домен/туннель, который смотрит на `PORT`).
3. Добавь бота **администратором** в канал `CHANNEL` (нужно для проверки подписки через `getChatMember`).
4. `ADMIN_IDS` — Telegram ID админов (команды `/admin`).

При старте бот сам ставит кнопку меню «Hider» → Mini App.

## Что реализовано (все экраны макета)

| Экран | Логика |
|---|---|
| Вход · подписка на канал | `getChatMember` по `CHANNEL`, состояния: не найдена / подтверждена (автопереход 2,6 с) |
| Главная, Профиль | подписка, дни, кольцо аватара, статистика, HWID, баннер из аватарки Telegram |
| Сброс HWID | подтверждение, успех, лимит раз в 24 ч с обратным отсчётом, «сбросов нет» |
| Запуск Hider | одноразовая команда `powershell -c "irm …/r/<token> \|iex"` (живёт `LAUNCH_TTL_MIN`, по умолчанию 10 мин), копирование, «устарела» |
| Теги | 5 бесплатных + 15 по 29 ₽, предпросмотр, установка, покупка |
| Покупка | подписка 7/14/30/90 дней, пакеты сброса HWID 1/3/5, промокод (−10 %) |
| Оплата | СБП, CryptoBot, FunPay, Telegram Stars; ожидание (15 мин), успех ×3, отмена, «время вышло» |
| Медиа и заработок | промокод автора (12 % с покупок), оплата за просмотры, правила, отправка роликов (TikTok/YouTube), «Мои ролики» |
| Вывод | карта РФ / FunPay / USDT (TRC-20, TON), минимум 500 ₽, история |
| Служебные | загрузка, бот недоступен, технические работы |

### Платежи — что нужно для боевого режима

* **Telegram Stars** — работает сразу с `BOT_TOKEN` (курс `RUB_PER_STAR`).
* **CryptoBot** — `CRYPTOBOT_TOKEN` (Crypto Pay API); оплата подтверждается опросом счёта.
* **СБП** — либо `SBP_URL_TEMPLATE` (ссылка на платёжную страницу эквайринга, `{order}` и `{amount}`) + вебхук
  `POST /webhooks/sbp` с заголовком `x-webhook-secret: SBP_WEBHOOK_SECRET` и телом `{order_id, amount}`,
  либо ручной режим `SBP_REQUISITES` — реквизиты показываются на экране оплаты, подтверждение командой `/confirm <id>`.
* **FunPay** — `FUNPAY_LOT_URL`; подтверждение вручную `/confirm <id>`.

Способ без настройки в интерфейсе показан неактивным («не подключено»).

### Видео для медиа
Данные ролика (дата, просмотры) берутся автоматически: TikTok — со страницы ролика, YouTube — через `YOUTUBE_API_KEY`.
Заявка принимается не позднее 2 дней после выхода; выплата: TikTok 1k/5k/10k просмотров = 25/150/300 ₽, YouTube (длинные) — 0,65 ₽ за просмотр.

### Админ-команды бота
`/orders`, `/confirm <id>`, `/grant <uid> <дней>`, `/media <uid> on|off`, `/videos`, `/video <id> [просмотры]|no [причина]`,
`/withdrawals`, `/wpay <id>`, `/wno <id> [причина]`, `/maintenance on [минут]|off`, `/user <uid>`.

### Клиент Hider
Команда запуска обращается к `GET /r/<token>[?hwid=…]`: токен гасится, привязывается HWID, растёт счётчик запусков, затем 302 на
`LAUNCH_PAYLOAD_URL?uid=…` (сам скрипт запуска Hider — вне этого репозитория).

## Разработка и проверка дизайна

`DEV=1` включает вход без Telegram (`/?dev=<id>`) и `/api/dev/seed` — **только для локальной проверки**.

* `node tools/e2e.mjs` — API-сценарии (оплата, промокоды, HWID, запуск, вывод).
* `node tools/design-check.mjs` — попиксельное сравнение экранов с PNG макета (нужны `design/png1/*`, их качает `design/fetch_png.py`).
* `design/fetch_psd.py` + `design/dump_psd.py` — выгрузка слоёв макета (размеры, шрифты, цвета), по ним верстались экраны.
